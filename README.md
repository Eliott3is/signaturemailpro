# signaturemailpro

Signature mail professionnelle d'Eliott Le Goff + hébergement des images via GitHub Pages.

- Aperçu / copie : https://eliott3is.github.io/signaturemailpro/
- Images : `photo.png`, `icon-phone.png`, `icon-mail.png`, `icon-linkedin.png` (servies depuis la racine)

## Mettre à jour
1. Modifier `index.html` ou remplacer une image (garder le même nom de fichier).
2. `git add . && git commit -m "maj signature" && git push`
3. Attendre ~1 min, puis recopier la signature depuis la page dans Apple Mail.

> Ne jamais renommer/supprimer une image : les mails déjà envoyés pointent dessus.
